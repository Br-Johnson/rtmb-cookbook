## Contributing

Corrections, clearer explanations, better exercises and reports of things that
did not work for you are all welcome.

### How to contribute

1. **Report a problem or suggest a change** by opening an issue in this repository.
   Say which episode, what you expected and what happened. A typo report is useful too.
2. **Propose a change** with a pull request:
   create a branch, make the change, and open a pull request against `main`.

### Before you open a pull request

- Build the lesson locally and check that your episode still runs
  (see "Build the lesson locally" in `README.md`).
- Keep to the style of the lesson: one recommended way to do each task,
  plain language, every figure with a text description (`fig.alt`),
  and every challenge with a solution.
- If you add something, say how long it takes to teach and what could be removed to make room.
  A workshop day is already full.

### What not to contribute

This lesson deliberately shows one way to do each task.
Please do not add alternative ways of doing the same thing unless you are replacing the current way with a better one.
